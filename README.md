# 벽을 부수는 거인

진격의 거인 모티브 3D 도시 파괴 브라우저 게임.
세 겹의 성벽에 둘러싸인 도시를 거인이 되어 부수고, 골드로 더 강한 거인을 사며 중앙 성채까지 돌파한다.

▶ 플레이: https://lc90me.github.io/titan-wall-breaker/

## 조작
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 버튼으로 펀치·발구르기·점프·스킬 (가로 화면 추천)
- PC: WASD 이동 · Shift 달리기 · Space 점프 · J 펀치 · K 발구르기 · L 스킬 · V 시점
